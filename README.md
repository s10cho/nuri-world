# 누리의 한글 왕국 🏰

미취학 아동(만 4~7세)을 위한 한글 학습 모험 웹앱.
지우개 몬스터가 지워 버린 글자들을 누리와 마법 토끼 포리가 되찾는 스토리를 따라,
**자음 19개 + 모음 21개 = 40개 자모**와 글자 조합, 받침 없는 단어를 게임으로 배웁니다.

## 구성 (5개 왕국 + 엔딩)

| 왕국 | 학습 내용 | 게임 |
|---|---|---|
| 1. 기억의 초원 (자음 왕국) | 자음 19개 — 훈민정음 제자원리 순서(상형 기본자 → 가획자 → 쌍자음) | 글자 만나기 → 소리 듣고 찾기 → 카드 짝 맞추기 |
| 2. 울림의 호수 (모음 왕국) | 모음 21개 — 기본자 → 초출자 → 재출자 → 합용자 | 〃 |
| 3. 글자 조각의 탑 (조합 왕국) | 자음+모음 → 음절 25개 (가, 나, 고, 구, 기 …) | 조각 맞춰 글자 만들기 |
| 4. 이름 없는 마을 (단어 왕국) | 받침 없는 단어 20개 | 사라진 글자 찾아 이름 완성, 주민 구출 |
| 5. 지우개 몬스터의 성 | 전체 복습 | 보스전 (정답으로 공격) |
| 🎉 왕국 축제 | 엔딩 | 구출한 주민 퍼레이드 |

- 스테이지별 별점(실수 횟수 기반) + 노력 지향 칭찬
- 도감: 모은 자모 40 / 만든 글자 25 / 구출한 주민 20
- 진행 상황은 기기(localStorage)에 저장

## 기술

- 순수 HTML/CSS/JS (ES 모듈) — 빌드 스텝 없음
- 한국어 음성: Web Speech API(기기 TTS), 효과음: Web Audio 합성 (외부 오디오 파일 없음)
- PWA 매니페스트 — 홈 화면에 추가하면 전체화면 실행 (iOS는 공유 → "홈 화면에 추가")
- 폰트: [Jua](https://fonts.google.com/specimen/Jua) (Google Fonts)

## 로컬 실행

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

(ES 모듈이라 file:// 로는 열 수 없고 HTTP 서버가 필요합니다)

## 음성 파일 생성

자연스러운 안내 음성은 OpenAI TTS로 미리 생성해 `public/assets/audio/ko/`에 저장할 수 있습니다.

```bash
npm run generate:voice -- --dry-run
OPENAI_API_KEY=sk-... npm run generate:voice
```

- 기본 모델은 `gpt-4o-mini-tts`, 기본 voice는 `nova`입니다.
- 변경 예: `OPENAI_TTS_MODEL=tts-1 OPENAI_TTS_VOICE=shimmer npm run generate:voice`
- 이미 생성된 파일은 건너뛰며, 다시 만들려면 `npm run generate:voice -- --force`를 사용합니다.

## GitHub Pages 배포

1. GitHub 저장소에 push
2. Settings → Pages → Branch: `main`, 폴더: `/ (root)` 선택
3. `https://<계정>.github.io/<저장소>/` 접속

모든 경로가 상대 경로라 하위 경로 배포에서도 그대로 동작합니다.

## 학습 설계 근거

딥리서치(학술 논문·상용 앱 분석, 22개 검증 근거) 기반:

- **파닉스(자소→음절→낱말) + 이야기 맥락 병행** — 만 4세 대상 KCI 실험연구에서 효과 검증, 토도한글 등 선도 앱의 커리큘럼 방식
- **자모 순서는 제자원리 기반** (가나다순 ❌) — 상형 기본자(ㄱㄴㅁㅅㅇ) → 가획자 → 병서 (KCI 김기영·이병규 2021)
- **터치 타깃 2cm 이상, 탭 중심, 시간 압박 없음** (NN/g 아동 사용성 연구)
- **명시적 음성+시각 피드백** — 6세 미만은 암시적 피드백을 해석하지 못함 (NN/g)
- **노력 지향 칭찬 + 수집형·스토리 진행형 보상** (핑크퐁 카드 수집 모델 참고)
- **세션 10~15분** — 스테이지 1~2개 분량 (토도한글 일일 학습 설계 참고)
