# 누리와 포리 — Gemini 동화 영상 제작 패키지

## 이번 제작 범위

첫 파일럿 **〈글자 씨앗에서 ‘나’가 자랐어요〉**의 생성 준비 자료입니다. 대상은 한글을 처음 접하는 4~7세로 가정합니다. 약 80초, 가로 16:9, 10개 장면이며 핵심 목표는 `ㄴ + ㅏ → 나`입니다. 영상·음성·새 참조 이미지는 아직 생성하지 않았습니다.

이야기: 누리와 포리가 싹이 나지 않는 화분을 발견합니다. 니은 씨앗과 아 물방울을 만나게 하고 아이와 함께 ‘나’를 읽자 새싹이 자랍니다. 글자가 식물을 자라게 한다는 설정은 동화적 상상입니다.

## Gemini에서 진행하는 순서

1. Gemini에 로그인하고 영상 생성 메뉴가 제공되는지 확인합니다. 표시되는 모델명, 길이·비율 옵션, 남은 생성량을 기록합니다.
2. 이미지 생성 대화에서 두 캐릭터 원본을 첨부하고 프롬프트 문서의 **기준 이미지 제작**을 실행합니다. 결과를 `ep01-reference.png`로 내려받습니다.
3. 기준 이미지의 캐릭터와 구도를 확인합니다. 원본 캐릭터 이미지는 세로형이므로 영상용 기준 이미지는 **가로 16:9**로 준비합니다.
4. 영상 생성 화면에 기준 이미지를 첨부합니다. **공통 영상 지시문 + 해당 장면 지시문**을 함께 입력해 한 장면씩 생성합니다. 각 요청에 참조를 다시 첨부하고 이전 대화의 기억만 믿지 않습니다.
5. 첫 시험은 S03 한 장면입니다. 캐릭터 유지, 빈 화분 표지판, 움직임이 적합하면 나머지를 진행합니다.
6. 결과를 `ep01-s01-v01.mp4`처럼 저장합니다. 수정본은 `v02`로 구분합니다. 실제 길이가 8초와 다르면 편집표에 맞춰 자르거나 정지 화면을 사용합니다.
7. 편집기에서 한국어 음성과 정확한 한글을 합성하고, 최종 영상을 내려받아 검수합니다. 출력 목표는 1920×1080, 16:9, MP4이며 원본 생성 해상도와는 별개입니다.

8초는 **이 패키지의 장면 설계 단위**입니다. 모든 Gemini 계정의 생성 길이가 8초라는 의미가 아닙니다. 생성 화면에서 선택할 수 있는 설정을 우선합니다. 여러 참조 이미지를 넣을 수 없다면 승인한 기준 이미지 한 장을 사용합니다.

## 음성과 글자

기본안은 Gemini에서 시각 장면과 잔잔한 환경음을 만들고 내레이션은 후반에 넣는 방식입니다. 캐릭터의 대사는 입 모양을 크게 움직이지 않는 동화 보이스오버로 처리합니다. 장면별로 목소리가 달라지지 않도록 전체 대사를 같은 녹음 세션에서 준비합니다.

Gemini 음성도 시험하려면 S03 지시문 끝에 다음을 추가합니다: `포리의 짧고 따뜻한 한국어 목소리로 정확히 “이 씨앗은 니은이야.”라고 한 번 말한다. 다른 말과 자막은 넣지 않는다.` 공통 지시문의 대사 없음 조건은 이 시험에서만 제외합니다. 발음과 목소리를 확인한 뒤 채택합니다.

학습 글자 `ㄴ`, `ㅏ`, `나`는 편집기 텍스트로 넣습니다. 자모의 이름 ‘니은’, 모음 읽기 ‘아’, 완성 음절 ‘나’를 구분합니다. 자동 자막을 학습 글자의 원본으로 사용하지 않습니다.

## 다음 동화로 확장

동일 캐릭터·그림체·제작 순서를 유지하고 장소와 학습 목표를 교체합니다.

- EP02 〈나비에게 온 편지〉: 동물 우체국, `나 + 비 → 나비`.
- EP03 〈모자를 주문했는데 모기가 왔어요!〉: 이상한 가게, `모자`와 `모기`의 다른 음절 찾기.
- EP04 〈바다로 가는 기차표〉: 장난감 기차, `바 + 다 → 바다`.

첫 편의 승인된 장면, 목소리, 글자 크기를 다음 편의 기준으로 남깁니다.
